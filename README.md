# StarSpektra

Веб-атлас определяет созвездия на снимках и измеряет цвет звёзд. Во вкладке «Цвет и температура» доступны фотометрия, калибровка камеры, журнал, экспорт CSV и модель Планка.

## Запуск

Файлы сайта находятся в папке dist. Для локального запуска выполни команду из корня репозитория и открой http://localhost:8000.

    python3 -m http.server 8000 --directory dist

## Render

Подключи ветку main репозитория к сервису Static Site.

| Настройка | Значение |
| --- | --- |
| Branch | main |
| Build Command | test -f dist/index.html && test -f dist/spectra/index.html |
| Publish Directory | dist |

Лицензии звёздного каталога, фотографий и декодера HEIC указаны в разделе «Данные и фотографии» на главной странице.
